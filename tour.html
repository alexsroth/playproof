Card Data Library

What a card is

Define the fields every card shares — name, cost, art, rules — with the right type for each. Templates live in one shared library, so you define a field set once and reuse it across games.

  • Fields
  • 6 field types
  • Shared templates
  • ~1,700 icons

Layout Designer

What a card looks like

A drag-and-drop canvas for text, art, icons, and shapes. Work in X-Ray to wire up structure, Style to apply your fonts and colors, Preview to see the finished card. Design once — every card follows.

  • Canvas + layers
  • X-Ray / Style / Preview
  • Binding
  • 9 built-in fonts
