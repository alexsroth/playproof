the golden path

Idea to printed deck.

Six steps from "I have an idea" to "I'm cutting cards at the kitchen table." You can skip around — but this is the through-line everything hangs off.

1 · Define the fields

Decide what every card tracks — name, cost, power, type, rules, art. These live in a Card Data Template, shared across your games. Pick a type per field (text, number, category, image, icon) so the app knows what it's handling.

[ field editor ]

2 · Enter the cards

Fill in rows one at a time, or paste a CSV and bulk-edit in a table. Each row is a card. Mess it up, fix it later — nothing's precious yet.

[ card table ]

3 · Design a layout

On a canvas, arrange the look of the card — text, numbers, icons, art frames, shapes. This is a Layout Template, and it doesn't care which game's data it gets. Build it once, reuse it everywhere.

[ layout canvas ]

4 · Bind the slots

Each placeholder on the layout is a slot. Wire it to a data column — "this slot shows the cost field" — or pin it to fixed text that prints on every card. This is where data and design finally meet.

[ slot → column binding ]

5 · Preview a real card

See an actual card render with real values — not a mockup, the thing itself. Flip through the deck, catch the text that overflows, fix the field, watch it update.

[ live card preview ]

6 · Print the deck

Export a print-ready PDF with real sizing and bleed. Print it, cut it, sleeve it, and get it to the table. Then snapshot the game and go break it in a playtest.

[ export → print sheet ]
